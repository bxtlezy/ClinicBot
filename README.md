# Поликлиника

Настольное приложение для записи пациентов на приём и работы сотрудников поликлиники. Интерфейс сделан на **PyQt6** с использованием **Qt Designer**, а данные сохраняются в **SQLite** через **SQLAlchemy**.

## Возможности

- Регистрация и вход с тремя ролями: пациент, врач и регистратор.
- Запись к конкретному врачу с выбором специальности, даты и свободного времени.
- Управление приёмами: отмена, отметка явки, заметки врача и перенаправление.
- Отзывы и оценки врачей, жалобы на отзывы и их рассмотрение.
- Управление врачами, специальностями и просмотр статистики.
- Подбор специальности по описанию симптомов.
- Генерация пароля, проверка полей и возможность запомнить вход на устройстве.

## Установка и запуск

В терминале из папки проекта:

```bash
python -m pip install -r requirements.txt
python main.py
```

При первом запуске базы данных создаются автоматически. **Первый зарегистрированный пользователь получает роль регистратора**, а следующие пользователи, зарегистрированные через обычную форму, — роль пациента. Аккаунты врачей добавляет регистратор.

## Кнопки и разделы приложения

### Вход

| Элемент | Что делает |
| --- | --- |
| **Войти** | Проверяет логин и пароль и открывает кабинет пользователя. |
| **Зарегистрироваться** | Открывает форму создания аккаунта. |
| **Запомнить вход на этом устройстве** | Сохраняет сессию, чтобы при следующем запуске не вводить пароль заново. |

### Регистрация

| Элемент | Что делает |
| --- | --- |
| **Сгенерировать надёжный пароль** | Создаёт случайный пароль из 20 символов и подставляет его в поле пароля. |
| **Копировать** | Копирует пароль в буфер обмена. |
| **Показать пароль** | Показывает введённый пароль вместо точек; повторное нажатие скрывает его. |
| **Зарегистрироваться** | Проверяет поля и создаёт аккаунт. После успешной регистрации предлагает войти. |
| **Назад** | Возвращает на экран входа без создания аккаунта. |

Обязательные поля: **логин, пароль, ФИО и телефон**. При ошибке появляется сообщение и красная подсказка под нужным полем. Номер начинается с `+7` и автоматически оформляется как `+7 999 123-45-67`; в базе сохраняется без пробелов и дефисов. Пароль должен содержать минимум 8 символов.

### Главное меню

| Кнопка | Что делает |
| --- | --- |
| **Обзор** | Показывает главную страницу с краткой информацией о записях. |
| **Записи на приём** | Открывает таблицу записей и действия с ними. |
| **Отзывы** | Открывает список отзывов о врачах. |
| **Врачи** | Открывает список врачей и управление ими; доступно регистратору. |
| **Обновить** | Заново загружает записи, отзывы, врачей и показатели из базы. |
| **Изменить пароль** | Запрашивает старый и новый пароль. После изменения нужно войти снова. |
| **Выйти из аккаунта** | После подтверждения завершает вход на устройстве и возвращает на экран авторизации. |

### Обзор и записи на приём

| Кнопка | Что делает | Кому доступна |
| --- | --- | --- |
| **+ Записаться к врачу** | Открывает форму новой записи из раздела «Обзор». | Пациент, регистратор |
| **+ Записаться** | Открывает такую же форму из списка записей. | Пациент, регистратор |
| **Отменить** | Отменяет выбранный приём после подтверждения. | Пациент, регистратор |
| **Оценить врача** | Предлагает поставить оценку от 1 до 5 и написать отзыв. Можно оценить только свой завершённый приём, если оценка ещё не оставлена. | Пациент |
| **Отметить явку** | Для выбранной записи позволяет выбрать «Пришёл» или «Не пришёл». | Врач |
| **Заметка** | Открывает редактирование заметки врача к выбранному приёму. | Врач |
| **Перенаправить** | Переводит выбранный приём к другому врачу с выбором свободного времени на ту же дату. | Врач |

Чтобы выполнить действие над записью, **сначала выберите строку в таблице**. Над таблицей есть строка поиска: она фильтрует записи по имени, врачу, дате, времени и статусу.

### Форма записи к врачу

В форме выбираются пациент (для регистратора), специальность, врач, день и доступное время. Также можно указать жалобы.

| Кнопка | Что делает |
| --- | --- |
| **Подобрать специальность по симптомам** | Анализирует введённые жалобы и предлагает подходящую специальность. Это подсказка, а не диагноз. |
| **Записаться** | Проверяет данные, сохраняет приём и возвращает к списку записей. |
| **Отмена** | Возвращает к записям без сохранения нового приёма. |

Календарь ограничен ближайшими 56 днями. В списке времени показываются доступные часы **конкретного выбранного врача**.

### Отзывы

| Кнопка | Что делает | Кому доступна |
| --- | --- | --- |
| **Пожаловаться** | Позволяет выбрать причину жалобы на выделенный отзыв. | Врач |
| **Рассмотреть жалобу** | Предлагает оставить отзыв или удалить его после рассмотрения жалобы. | Регистратор |

Перед нажатием необходимо **выбрать отзыв в таблице**.

### Врачи и специальности

| Кнопка | Что делает |
| --- | --- |
| **+ Врач** | Открывает форму добавления врача: логин, пароль, ФИО, телефон, специальность. |
| **Изменить** | Открывает форму редактирования выбранного врача. Можно поменять данные и при необходимости пароль. |
| **Удалить** | Удаляет выбранного врача после подтверждения. |
| **+ Специальность** | Предлагает ввести название новой специальности и добавляет её в базу. |
| **Статистика** | Показывает количество записей, пациентов, врачей и записи по статусам. |

Этот раздел доступен **регистратору**. Для изменения или удаления врача нужно сначала выделить его строку в таблице.

### Форма врача

| Кнопка | Что делает |
| --- | --- |
| **Сохранить** | При добавлении создаёт аккаунт врача; при редактировании сохраняет изменения. |
| **Отмена** | Возвращает к списку врачей без сохранения. |

## Структура проекта

```text
main.py             запуск приложения
gui.py              окна, меню и обработчики кнопок
service.py          авторизация и логика работы поликлиники
database.py         модели SQLAlchemy и подключение к SQLite
styles.qss          стили интерфейса
requirements.txt    зависимости
ui/                 формы Qt Designer (.ui)
data/               локальные базы данных
```

В папке `data/` создаются две базы:

- `accounts.db` — пользователи, хеши паролей и сохранённые сессии;
- `clinic.db` — записи на приём, специальности и отзывы.

Пароли сохраняются в виде хешей, а запоминание входа работает через отдельный токен, хранящийся на устройстве. Для настоящих персональных и медицинских данных потребуется дополнительная защита.

## Изменение интерфейса

Файлы из папки `ui/` можно открывать в **Qt Designer**. После изменения достаточно сохранить `.ui` и заново запустить программу. Конвертировать формы в Python не нужно. При переименовании кнопок и полей важно учитывать их `objectName`, поскольку `gui.py` обращается к элементам по этим именам.

При публикации проекта не стоит загружать личные базы `*.db`, папку `.idea/` и виртуальное окружение — их можно исключить через `.gitignore`.
